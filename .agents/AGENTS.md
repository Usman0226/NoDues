# Agents Constitution and Operational Guidelines

This file defines the agent guidelines for the NoDues project adhering to the Engineering Constitution.
- Scalability target: 3,000 sustained / 9,000 peak concurrent users.
- Clean, production-grade UI matching the institution's design standards.
- No placeholder data or half-built components.
- Zero console errors, fully responsive, error boundaries at root and route levels.
- Strict adherence to state logging and error taxonomies.
